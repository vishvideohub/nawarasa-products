NAWARASA PRODUCTS WEBSITE

1. Open your GitHub repository: nawarasa-products
2. Open index.html and choose Edit (pencil).
3. Replace the entire file with this index.html, or use Add file > Upload files to upload this file and overwrite the existing index.html.
4. Commit changes to the main branch.
5. Wait for GitHub Pages to publish, then hard-refresh the site with Ctrl+Shift+R.
